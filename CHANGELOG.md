# Changelog

## 0.1.0 — 2026-11-16

- First release. DynoTable SQL (`.dtsql`, `.dynotable.sql`) and PartiQL (`.partiql`) files get
  completion, diagnostics, hover, formatting, rename of table aliases and inlay hints from the
  DynoTable app.
- Run: a ▶ in the gutter runs a statement and prints its rows as a table in the terminal panel.
  Needs `dynotable-cli` 0.1.2 or later.
